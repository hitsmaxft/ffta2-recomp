# Public data

Published by explicit owner request: decoded retail text and numeric address
information, plus incomplete Terra translation drafts. No ROM image or raw
retail binary is included. Retail text belongs to its respective rights holders;
the repository software license does not relicense that text.

Read text/manifest.json for snapshot coverage. CSV files use UTF-8 BOM, quoted
fields and CRLF records; embedded newlines require a real CSV parser. Blank
translations remain untranslated. Review rows are rejected by the importer.
Planning-accepted rows still require runtime encoding and gameplay validation.
No naming screen replacement is implemented.
